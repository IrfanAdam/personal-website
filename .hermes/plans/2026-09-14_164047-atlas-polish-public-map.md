# Architecture atlas polish + public map on main page

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Make the `/ds/#/atlas` canvas genuinely useful — floating glass control dock on the canvas, fit-to-view, hover/selection emphasis via dimming, edge routing, hover tooltips — then expose a distilled public map of the DS architecture on the main portfolio page (`/#/minimal-lab` hub + `/lab/architecture` viewer detail), reusing the clicker mechanics-map pattern (fullscreen canvas view, floating controls, floating legends, cursor tooltip).

**Architecture:** Keep `arch-schema.json` as the single source. Phase 1–2 rework `pages-atlas.js` + `atlas/` modules: controls move from a stacked toolbar into a floating dock (top-right: mode select + hide chrome; bottom-left: replaceable legend pills, toggles get square dot fill), canvas auto-fit + node/edge emphasis, SVG edge paths (module-boundary orthogonal, intra-block bezier), permanent legend for layer + edge kinds, hover tooltip + click-pinned tooltip. Phase 3–4 distill a curated public schema subset (mechanics-map style: curated nodes with `desc`, ranked edges `call/data/signal`) into `src/js/views/map/data.js` + a `mechanics`-style canvas view served on the main site — `/lab/architecture` reachable from Minimal Lab card on `/#/minimal-lab-map`, and from project details. No DS-path duplication: public map reads a generated curated file, DS atlas stays admin.

**Tech Stack:** Vite 5 ESM, vanilla JS, SVG (atlas) + Canvas2D (public map, port of clicker `mechanics/render.js`), existing gates (`lint-manage.mjs`, `lint-tokens.mjs`, `ds-track.mjs`, `map-graph.mjs`, `smoke.mjs` on 5199)
