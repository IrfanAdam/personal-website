# DS Elements sheets get Foundations-style vertical tabs

**Goal:** Primitives, Library, and Patterns stop scrolling all sheets at once — each sheet becomes a pane behind the same vertical tab rail Foundations uses.
**Architecture:** Keep the shared `tabs({vertical:true})` shell and sheet builders untouched; composers (`pages-primitives`, `pages-library`, `pages-patterns`) build a labelled pane per sheet, and the Patterns section modules split into per-pane exports. Mount functions and rail CSS are reused as-is.
**Tech Stack:** Vanilla JS + Vite, `src/ds/tabs.js`, `src/ds/pages-*.js`, `src/ds/patterns-*.js`.
**Tags:** Design System, Component
