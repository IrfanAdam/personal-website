# Smart Changelog — Tags, Filters, Plan SOP

**Goal:** Changelog tracks work by tag: every plan carries a few closed-taxonomy tags (auto-inferred, explicitly overridable), the archive filters by chips, iteration numbers recompute client-side on the filtered list, and large prompts auto-suggest a phased tagged plan before implementation.

**Architecture:** `src/ds/changelog-tags.js` owns the taxonomy + tagger (pure, imported by both the Vite renderer and the Node suggester). `pages-changelog.js` adds a chip row, filters Miller columns client-side, derives `Iter N` from the filtered list. `scripts/plan-suggest.mjs` turns a large prompt into a tagged plan skeleton. Convention persisted in `README.md § DS conventions`.

**Tech Stack:** Vanilla JS modules, `import.meta.glob` plans, `var(--token)`-only CSS ≤100 lines/file, `npm test` gate. Commits cite `[plan:2026-09-10_195043-smart-changelog.md#phase-N]`.
