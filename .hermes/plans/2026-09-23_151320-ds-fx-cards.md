# FX + Motion legible — what each token changes, one screen

**Goal:** Make Foundations → FX and Motion explain what each token changes with plain-language tables behind pill tabs — one screen per effect, no scroll, live values intact.
**Architecture:** Replace the flat FX token grid and stacked Elevation/Motion sections with the pill `tabs()` + `fx-table` pattern; keep live `data-live`/`data-copy-token` behavior and demos inside their tabs, only the token presentation changes to rows with effect/token/what/live.
**Tech Stack:** Vanilla JS + Vite, DS Foundations renderers (`tabs.js`, `foundations-fx.css` `fx-table`), token-only CSS.
**Tags:** Design System, Component, Motion
