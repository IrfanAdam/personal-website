# Masonry Grid Optimisation Plan

> **For Hermes:** implement task-by-task; verify after each phase before proceeding.

**Goal:** True shortest-column masonry with fade-in slotting, dimension-first blur-to-sharp lazy loading, and list view folded into the icon tab group.

**Architecture:** Replace CSS `columns:` balancing with a JS shortest-column distributor over real image ratios baked into data at build time; progressive `<img>` (reserved box → blur → sharp → fade-in); unify view switcher so list is a 4th icon tab. No new dependencies.

**Tech Stack:** Vanilla JS + CSS (existing), `sips` for one-off asset measuring, Vite build.

---

## Studied: current dynamics

- `src/views/masonry.js:1` — grid is CSS `columns: 4 240px`. Browser fills top-to-bottom, balances columns. **Not** lowest-vertical-fill; item order goes down column 1, not across.
- `src/styles/masonry.css:13-15` — heights are faked with `nth-child` aspect-ratio hacks, unrelated to real images.
- Real images are near-uniform portrait (~683×1024, all ~2:3). Shortest-column only shows its value once real ratios drive layout.
- No dimension reservation (CLS on load), no blur-up, plain `loading="lazy"`.
- Weight: `public/images` 6.2M, `public/icons` 2.7M. Worst: `icons/tas-69.jpg` is 5465px wide yet rendered at 56px in the strip (`pages.css:4`). Icons are the Phase 1 win.
- `index.html:19-26` — Index/Masonry/Contact are separate nav pills; `▦ ☰ ⋮⋮` buttons only set column count. Framer folds list view into the icon group.
- Leak: `main.js:18` replaces `innerHTML` on route change; `mountMasonry` listeners are never unmounted.

## Phase 2 — True masonry + progressive load

### Task 3: Bake real dimensions into data
- New: `scripts/dims.mjs` (ESM — use `fileURLToPath(import.meta.url)`, never `new URL().pathname`; spaces in path break otherwise). Reads `public/images/*` via `sips`, writes `content/dims.json` `{slug: [w,h]}`.
- `src/data/site.js` — append `[w, h]` to each project tuple from `dims.json` (fallback 3:4 if missing).
- Files stay <100 lines each (repo rule). Verify: `node scripts/dims.mjs`, import logs correct ratios; build green.

### Task 4: Shortest-column distributor
- New: `src/views/masonry/layout.js` — `distribute(items, nCols)`: accumulate estimated heights (`colWidth * h/w + textBlock`) into per-column totals, place each item in lowest-fill column. Pure function, no DOM.
- `mountMasonry` renders N column divs instead of flat list; re-runs on `setCols` / filter change.
- Reflow guard: `ResizeObserver` + rAF-throttle, only re-distribute when column *count* changes (breakpoints), not every pixel.
- Verify: with 14 near-uniform portraits columns stay even; spot-check by temporarily shuffling one tall item — it must land in shortest column. `setCols(2/3/4)` repacks correctly.

### Task 5: Dimension-first blur-to-sharp + fade-in slot
- Card markup: `<span class="img" style="aspect-ratio:W/H"><img width height loading="lazy" decoding="async" …>` — box reserved pre-load (zero CLS).
- CSS: `.card` starts `opacity:0; translate:Y(8px)`; on per-card `img.onload` add `.ready` → `opacity:1; translate:0` (~250ms ease) + `filter:blur(0)` from `blur(16px)` over shimmer background (`var(--chip)` tokens only, no raw colors).
- Stagger: `transition-delay` capped (e.g. `min(index*30ms, 300ms)`), disabled under `prefers-reduced-motion`.
- Verify: throttled-3G load shows boxes → blur → sharp + rise; no layout shift; animation jank-free.

## Risks / tradeoffs
- JS distributor replaces CSS columns: no-JS fallback lost (acceptable for portfolio SPA; keep CSS `columns` as progressive-enhancement fallback if cheap).
- Real ratios are near-uniform, so shortest-column looks similar today — value appears as new varied-aspect stories are added via CMS. New CMS uploads need dims: document re-running `scripts/dims.mjs` (or default 3:4).
- Blur-up via CSS shimmer (no LQIP assets) keeps it dependency-free but less pretty than true tiny-thumbs; revisit only if shimmer looks cheap.

## Decisions (confirmed 2026-09-07)
- Blur style: CSS shimmer + `blur()` transition, zero extra assets.
- `#/` redirects to the masonry list tab; no standalone index page (Home list renderer moves into masonry view).
