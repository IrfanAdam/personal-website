# Plan — Repair the split-refactor regressions in the DS labs

**Goal:** Every module the refactor split back into pieces works again: the Scramble lab mounts and all its controls respond, the Glitch lab's Code tab actually shows code, the Library page renders, the GridReveal lab canvas draws, and the changelog's empty-filter state stops throwing. Plus a sweep for the same class of breakage elsewhere.
**Architecture:** The splits moved handlers into sibling modules but left call sites pointing at names that were never imported or were deleted — a static free-identifier scan of `src/` (esbuild-free, regex+state-machine) plus a fresh-page browser sweep per route localises every instance. Fixes restore the original wiring per module: `bind.js` re-attaches the Scramble controls and hands its listener list to `teardown.js`; handlers that already live in `bind-sound.js`/`bind-ui.js` are consumed, not duplicated.
**Tech Stack:** Vite · vanilla ESM · Node (scan script, temporary) · ds-track
**Tags:** Component, Function, Tooling
