# Architecture Audit + Atlas Canvas Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship a single switchable Atlas canvas (`/ds/#/atlas`) showing Functions, Components, and Foundations schemas with their connectors, backed by a maintained schema that regenerates on every change.

**Architecture:** Audit the tree into evidence first, then extend `map-graph.mjs` to emit a machine schema (`arch-schema.json`) alongside `graph.mmd`, then build one SVG Atlas route with layer toggles + inspector, then wire regeneration into build/predev so views stay real-time.

**Tech Stack:** Vite 5 ESM, vanilla JS + inline SVG (no deps), existing gates (`lint-manage.mjs`, `lint-tokens.mjs`, `ds-track.mjs`, `map-graph.mjs`, `smoke.mjs` on 5199)

**Tags:** Design System, Component, Function, Tooling

---

## Context / assumptions

- Root: `/Users/irfan/Documents/Portfolio Redo/personal_website`; `npm test` = `lint:tokens && build`.
- Route table (`src/ds/routes.js`): 16 routes — Start (changelog, overview, foundations), Components (primitives, library, components, patterns), Functions (index + 7 labs: grid-reveal, shimmer, rise, viewer, glimmer-orb, glitch, scramble).
- Foundations: 7 panes (`pane-color/type/space/shape/motion/fx/contract`) + 6 subfolders (color, fx, motion, shape, space, type), ~20 modules.
- Components: 11 primitives (avatar, badge, btn, divider, field, field-code, field-meta, kicker, logo, tag, toggle) + 11 library (spec, header, strip, next, filters, contact, cta, hero, work, card, footer) + component.js + patterns.
- Function labs carry submodules (glitch 7 files, scramble 11 files) wired to `src/views/*` production counterparts.
- Existing graph: `docs/graph.mmd` (344 lines) generated by `scripts/map-graph.mjs` from static JS `import` lines only — no CSS/token edges, no layer labels, static doc not a canvas.
- Standing rules: ≤100 lines/file all languages, tokens via `var()` only, ADAM header + export map + section banners, kebab-case noun-first, `docs/graph.mmd` no orphans/cycles, `[plan:<file>#phase-N]` trailers, `changelog-names.json` entry before implementation, smoke on 5199 never 5173.
- Implementer adds the `changelog-names.json` entry for this file FIRST (Task 1), else `npm run plan:names` fails.

## Risks / open questions

- SVG canvas scope creep (force-layout physics) — mitigated: deterministic layered columns + one radial mode, no physics engine.
- Schema drift if regeneration is manual — mitigated: Phase 5 wires it into `build` + `predev` (Phase 5 owns the `package.json` edit, single place).
- `atlas.css` vs 100-line cap — mitigated: reuse `.ds-table`/`.ds-pick` chrome, new file capped, counted after each edit.
