# DS docs — compact flow, no loose gaps

**Goal:** DS documentation reads as one continuous column — tabs sit on a single hairline and the next section flows directly off it, no orphaned gap or double rule like the Glitch lab screenshot.
**Architecture:** Phase 1 fixes the only custom horizontal tabset (Glitch `ds-tablist--line` + `[data-tab-panel]`) — CSS makes the panel's first `.ds-sec` flush under the tablist's hairline. Later phases extend the same rule to every horizontal tabset and collapse redundant `.ds-sec` tops that stack after a hero.
**Tech Stack:** Vanilla CSS tokens (`var(--space-*)`, `var(--border-hairline)`), `src/ds/ds-tabs.css` as the single owner of tab→panel rhythm; `src/ds/functions/glitch.js` keeps its `.ds-sec` wrapper — no markup split.
**Tags:** Design System, Component
