# DS Nav — Collapsible Sidebar + Phase Drawer

**Goal:** Fix DS navigation friction: the sidebar collapses (persisted), and phase detail leaves the Miller columns for a right-hand drawer with prev/next stepping inside the iteration.

**Architecture:** `ds.js` owns the sidebar toggle (body class + localStorage, desktop-only). `pages-changelog.js` owns the drawer (fixed panel + scrim, open on sprint click, prev/next over visible sprints, Esc/scrim closes). New styles pack into `ds.css` without breaking the 100-line ceiling.

**Tech Stack:** Vanilla JS modules, `var(--token)`-only CSS ≤100 lines/file, `npm test` gate. Commits cite `[plan:2026-09-10_201154-ds-nav-drawer.md#Phase-N]`.
